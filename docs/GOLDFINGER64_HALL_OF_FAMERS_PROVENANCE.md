# Goldfinger 64 Hall-of-Famers — source and attribution

GoldenEye 007 Plus imports selected N64-native head resources from the **Goldfinger 64** ROM supplied by the user. Goldfinger 64 is a GoldenEye ROM-hack project created by members of the GoldenEye 007 modding community. This initial pilot imports **SubDrag** and **Trevor** as selectable characters.

- Character models and textures: original Goldfinger 64 resources, preserved byte-for-byte except for texture ID rebasing required to avoid collisions in GE+.
- Goldfinger 64 project: credited to the Goldfinger 64 development team, prominently SubDrag, Trevor, Sogun and other contributors (see the project's original credits).
- Heads are named for the contributors; naming the character does not assert that person individually authored their own model.
- This integration was done for GoldenEye 007 Plus; it does not claim authorship of the original faces or textures.
- No retail GoldenEye, Josh_7774, Tegguy1989 or original Shaun resource was replaced.

Original project page: https://n64vault.com/ge-campaigns:goldfinger-64
